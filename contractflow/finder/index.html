Verification and approval controls

This review build uses publicly published project details only; it contains no private client records, portal credentials or submission controls. Open records are conservatively removed from the default result set 48 hours after their date-only source verification. If the exact closing hour is unknown, open records are also removed from the start of the published closing date (AWST). Technical eligibility, current availability, full SOW and buyer access must be checked at the source. An EOI is not an award or a guaranteed contract.
